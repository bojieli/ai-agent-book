# 实验 6-14：RGB 视觉策略的跨环境测试

看一眼[训练图](validation/runs/local-gpu/source_preview.png)，再看[测试图](validation/runs/local-gpu/target_preview.png)。即使背景和颜色都变了，你大概仍能指出圆点应该往哪个方向移动才能靠近方框。用固定配色训练出来的模型也能做到吗？我们用同一道五分类题，比较四种训练方式。

<a id="learning-0"></a>

## 先给一张图标上动作

每张图有 32 × 32 个像素，圆点表示物体，方框表示目标。[图像生成代码](pipeline.py)先随机选出两者的位置，再计算动作标签。假设方框在圆点的右上方，横向距离比纵向距离大，这张图的标签就是向右。横纵两个方向的归一化距离都小于 0.10 时，标签才是 `grasp`。在预览图里挑一对圆点和方框，试着按这条规则给它标一个动作。

接下来的训练都沿用这条规则，只改变图像怎样画出来。下表列出了三个随机种子的平均分类准确率。左列测试图像与固定配色的训练图来自同一分布，右边两列换成有条纹和噪声的画面，其中最后一列的背景更亮。[逐次结果与汇总](validation/runs/local-gpu/matrix.json)

| 训练条件 | 固定配色 | 条纹背景 | 较亮条纹背景 |
| --- | ---: | ---: | ---: |
| 固定背景与配色（`source_clean`） | 93.0% | 54.8% | 56.5% |
| 主要改变背景（`source_background`） | 90.9% | 36.9% | 52.9% |
| 主要改变物体与目标的外观（`source_appearance`） | 89.2% | 74.4% | 83.1% |
| 组合改变背景、外观、亮度与噪声（`source_full`） | 87.5% | 76.1% | 80.2% |

## 准备运行环境

只读结果可以直接打开上面的图和表。亲自训练需要 Python、NumPy、Pillow，以及能使用 CUDA 或 Apple MPS 的 PyTorch。图片和标签由脚本在本地生成，无需下载基础模型或采集相机图像。仓内这次运行使用 Apple MPS 和 PyTorch 2.7.0。正文编号为 6-14，脚本和归档证据沿用早期编号 `6-13`。

<a id="learning-2"></a>

## 在相同测试集上比较四种训练方式

从仓库根目录运行以下命令。新的输出写入独立目录，方便和随书数据逐项比对。

```bash
cd chapter6/rgb-sim2real-grasping
python pipeline.py --train-size 4096 --test-size 1024 --epochs 10 --seeds 20260808,20260809,20260810 --output-dir validation/runs/my-run
python validate_evidence.py validation/runs/my-run/evidence.json
```

每个种子分别训练四次。网络结构和训练量相同，每次用 4096 张图训练 10 轮，再在每个测试环境上各做 1024 道题。输出包括第一个种子的组合变化策略检查点、训练指标、逐种子结果矩阵、画面预览和各产物的 SHA-256。可以先对归档版本运行同一个校验程序，把最后一个参数换成 `validation/runs/local-gpu/evidence.json`。

## 怎样判断视觉迁移有没有改善

先沿第一行横着读。固定配色下答对了 93.0%，换成条纹背景后只有 54.8%，这就是这套策略遇到的迁移问题。再沿条纹背景这一列竖着读。只改训练背景，准确率降到 36.9%；把几种变化组合起来训练，才升到 76.1%。换到较亮的测试环境，主要改变外观的一组又超过了组合变化的一组。选择训练条件时，先想清楚部署时会遇到哪种画面，再去看对应的列。

[验收程序](validate_evidence.py)检查三个种子的平均表现。固定画面策略在原环境的准确率须超过 0.85；组合变化的策略在两个目标环境都须超过 0.65，且分别优于固定画面策略。试着单看第一个种子，再与均值比较，它会怎样改变你对这两种策略的判断？

这里测到的是合成图像上的动作分类准确率。真机抓取还要验证相机标定、真实参数和动作执行后的状态，并准备急停、观察员与 SO100 硬件。[上游版本记录](upstream.lock.json)保留了 LeRobot 和 ManiSkill 的硬件扩展路径。哪些画面变化适合继续加入这个分类实验？哪些变化需要重新定义标签，或走到真机上才能检验？
