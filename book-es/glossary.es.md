# Glosario de Términos Inglés - Español {.unnumbered}

En la traducción al español de este libro sobre Agentes de IA, se ha adoptado el principio de mantener los **términos técnicos consolidados en inglés** o utilizarlos junto con sus traducciones estándar en español, garantizando la máxima precisión técnica sin perder claridad ni introducir traducciones forzadas que generen ambigüedad.

La siguiente tabla incluye los términos clave utilizados a lo largo del libro:

| Término en Inglés | Uso Recomendado en Español | Descripción / Significado en Español | English Description |
| --- | --- | --- | --- |
| Ablation study | Estudio de ablación (*Ablation Study*) | Experimento que desactiva o sustituye un componente manteniendo fijas la tarea y las condiciones de ejecución, para medir cuánto aporta ese componente al resultado. | An experiment that disables or replaces one component while keeping the task and run conditions fixed, to measure how much that component contributes to the result. |
| Action Space | Espacio de acción (*Action Space*) | Conjunto de acciones que el Agente puede emitir (llamadas a herramientas, respuestas, operaciones de interfaz). Junto con el espacio de observación, delimita la interfaz entre el modelo y el mundo. | The set of actions an Agent is allowed to emit (tool calls, replies, interface operations). Together with the observation space, it defines the interface between the model and the world. |
| Agent | Agente / Agente de IA | Sistema que, a partir de un LLM, el contexto y las herramientas, comprende la tarea, planifica, actúa, observa los resultados y ajusta el plan hasta completarla. Se resume como Agente = modelo + Harness. | A system that uses an LLM, context, and tools to understand a task, plan, act, observe results, and adjust its plan until the task is done. Summarized as Agent = Model + Harness. |
| Agent bootstrapping | Arranque autónomo (*bootstrap*) | Proceso por el cual un Agente escribe, prueba y mejora poco a poco su propio código y sus herramientas, hasta poder seguir desarrollándose a sí mismo. | The process by which an Agent gradually writes, tests, and improves its own code and tools until it can keep developing itself. |
| Agent skills | Skill / Agent Skills | Paquete de instrucciones, scripts y recursos que se carga en el contexto solo cuando la tarea lo necesita; el prompt del sistema conserva únicamente sus metadatos. | A package of instructions, scripts, and resources loaded into the context only when the task needs it; the system prompt keeps only its metadata. |
| Agent Status Bar | Barra de estado del Agente (*Agent Status Bar*) | Resumen mantenido por el Harness con contadores, progreso de la gestión y asuntos pendientes de confirmar; se actualiza con los mensajes y se añade al final del contexto para no romper el prefijo estable. | A Harness-maintained summary of counters, task progress, and items awaiting confirmation; it is updated with the messages and appended to the end of the context so the stable prefix stays intact. |
| Agentic RAG | RAG agéntico (*Agentic RAG*) | Sistema RAG en el que el propio Agente decide si busca más, qué busca y cuándo tiene información suficiente. | A RAG system in which the Agent itself decides whether to search further, what to search for, and when it has enough information. |
| Agentic Reinforcement Learning | Aprendizaje por refuerzo agéntico (*Agentic Reinforcement Learning*) | Aprendizaje por refuerzo que incorpora al entrenamiento la llamada a herramientas y la interacción de varios pasos con el entorno, de modo que el modelo aprende estrategias de Agente completas. | Reinforcement learning that brings tool calling and multi-step interaction with an environment into training, so the model learns complete Agent strategies. |
| Agentic workflow | Flujo de trabajo agéntico (*Agentic workflow*) | Flujo de ejecución dinámico e iterativo (planificación, ejecución, evaluación, corrección) gestionado por un LLM en lugar de una generación lineal de un solo paso. | Dynamic and iterative execution flows (planning, execution, self-correction) managed by an LLM instead of fixed, linear single-step generation. |
| Alignment | Alineación (*Alignment*) | Proceso de entrenamiento y ajuste para garantizar que el comportamiento y las salidas de un modelo coincidan con los valores y reglas humanas. | The process of training and tuning AI models to ensure their behavior and outputs match human values, intentions, and safety guidelines. |
| Alignment tax | Impuesto de alineación (*Alignment tax*) | Ligera reducción en la capacidad general o creatividad de un modelo como efecto secundario del entrenamiento de seguridad o alineación. | A slight drop in a model's general capability or creativity that can occur as a side effect of safety or alignment training. |
| API key | API Key / clave de API | Clave secreta utilizada para autenticar una aplicación o Agente ante servicios o API externas. | A secret key used to authenticate an application or Agent with external services or APIs. |
| Artifact | Artefacto / producto externo (*Artifact*) | Resultado que el Agente produce fuera del contexto durante una tarea (archivos de código, informes, documentos, imágenes, resultados estructurados); puede verificarse y conservarse de una tarea a otra. | An output the Agent produces outside the context during a task (code files, reports, documents, images, structured results); it can be verified and carried over from one task to the next. |
| Assistant role | Respuestas del modelo (*Assistant Messages*, rol `assistant`) | Mensajes del historial generados por el modelo: incluyen el texto dirigido al usuario, las llamadas a herramientas y, según el servicio, la información de razonamiento. | Messages in the history generated by the model: they include user-facing text, tool calls, and, depending on the service, reasoning information. |
| AST (Abstract Syntax Tree) | Árbol de Sintaxis Abstracta (AST) | Representación en árbol de la estructura de código fuente según las reglas sintácticas de un lenguaje de programación. | A tree representation of source code structure based on programming language syntax. |
| Asynchronous execution | Ejecución asíncrona (*Async execution*) | Forma de trabajo en la que el Agente sigue avanzando en la tarea sin bloquear la interacción, incluso después de que el usuario se haya marchado, y comunica los resultados cuando están listos. | A way of working in which the Agent keeps making progress without blocking the interaction, even after the user has left, and reports results when they are ready. |
| Audit log | Registro de auditoría (*Audit log*) | Registro cronológico de eventos y acciones críticas del sistema, utilizado para seguridad, rastreo y depuración. | A chronological record of critical system events and actions, used for security, tracing, and debugging. |
| AutoGen | AutoGen | Marco de trabajo de código abierto popular para construir sistemas multi-agente y flujos de trabajo colaborativos. | A popular open-source framework for building multi-agent systems and cooperative workflows. |
| Autonomous Agent | Agente autónomo (*Autonomous Agent*) | Agente que elige el siguiente paso según la situación, en lugar de seguir una ruta fijada de antemano en el código. | An Agent that chooses its next step based on the situation rather than following a path fixed in code beforehand. |
| Benchmark | *Benchmark* / evaluación comparativa | Conjunto estandarizado de pruebas y tareas utilizado para medir y comparar el rendimiento de modelos o sistemas. | A standardized suite of tests and tasks used to measure and compare model or system performance. |
| Bi-encoder | Codificador doble (*bi-encoder*) | Arquitectura de recuperación que codifica consultas y documentos por separado en vectores, lo que permite búsquedas de similitud muy rápidas. | A retrieval architecture that encodes queries and documents separately into vectors, enabling very fast similarity searches. |
| BM25 retrieval | Recuperación BM25 (*BM25 retrieval*) | Algoritmo tradicional y efectivo de búsqueda de documentos basado en la frecuencia de términos y la longitud del documento. | A highly effective, traditional keyword-based document retrieval algorithm based on term frequency and document length. |
| Browser automation | Automatización de navegador (*Browser automation*) | Control autónomo de un navegador web por parte de un Agente (hacer clic, escribir, desplazar) usando herramientas como Playwright o Puppeteer. | Autonomous control of a web browser (e.g., clicking, typing, scrolling) by an Agent using tools like Playwright or Puppeteer. |
| Cache hit / miss | Acierto / fallo de caché (*Cache hit / miss*) | Condición donde los datos solicitados se encuentran en la caché (*hit*) o deben calcularse/recuperarse desde cero (*miss*). | Whether requested data is found in cache (hit) or needs to be calculated/retrieved from scratch (miss). |
| Centralized scheduling | Planificación centralizada (*Centralized scheduling*) | Patrón de coordinación multi-agente donde un gestor central determina qué Agente habla o actúa a continuación. | A multi-agent coordination pattern where a central manager determines which Agent speaks or acts next. |
| Chain of Thought (CoT) | Cadena de pensamiento (*Chain of Thought*, CoT) | Pasos lógicos intermedios que el modelo genera antes de dar la respuesta final. | Intermediate logical steps the model generates before giving its final answer. |
| Chunking | Fragmentación (*chunking*) | Proceso de dividir textos grandes en segmentos más pequeños y significativos para incrustación y búsqueda RAG. | The process of splitting large texts into smaller, meaningful segments for embedding and RAG retrieval. |
| Coding Agent | *Coding Agent* | Agente especializado en escribir, ejecutar, probar y modificar código; con el sistema de archivos como espacio de trabajo, sirve también de núcleo de ejecución de un Agente general. | An Agent specialized in writing, running, testing, and modifying code; with the file system as its workspace, it also serves as the execution core of a general-purpose Agent. |
| Computer Use | *Computer Use* | Tipo de tarea en la que el Agente deduce el estado de la interfaz a partir de capturas de pantalla, DOM o árbol de accesibilidad, y la opera con ratón y teclado como una persona. | A type of task in which the Agent infers the interface state from screenshots, the DOM, or the accessibility tree, and operates it with mouse and keyboard as a person would. |
| Context | Contexto (*Context*) | Toda la información (prompt del sistema, definiciones de herramientas, observaciones, memoria del usuario, historial) disponible para el modelo en una llamada; el «campo de visión» de la decisión actual. | All the information (system prompt, tool definitions, observations, user memory, history) available to the model in one call; the "field of view" of the current decision. |
| Context Anxiety | Ansiedad de contexto (*Context Anxiety*) | Tendencia del modelo a apresurarse o cerrar la tarea antes de tiempo cuando percibe que la ventana de contexto está a punto de agotarse. | A model's tendency to rush or wrap up a task prematurely when it senses the context window is about to run out. |
| Context Compression | Compresión de contexto (*Context Compression*) | Estrategias que, cuando el historial crece, conservan los hechos clave, las restricciones y el progreso y descartan el resto, para ajustarse a la ventana de contexto y reducir costes. | Strategies that, as history grows, keep key facts, constraints, and progress and drop the rest, to fit the context window and reduce cost. |
| Context Engineering | Ingeniería de contexto (*Context Engineering*) | Selección, organización y actualización de toda la información que el modelo recibe en cada llamada (prompts, herramientas, historial, memoria, RAG) para lograr precisión y un coste óptimo. | Selecting, organizing, and updating all the information the model receives in each call (prompts, tools, history, memory, RAG) for accuracy and optimal cost. |
| Context Rot | Putrefacción del contexto (*Context Rot*) | Empeoramiento del rendimiento del modelo a medida que crece el contexto, aunque no se haya alcanzado el límite de la ventana. | The degradation of model performance as the context grows, even before the window limit is reached. |
| Context Window | Ventana de contexto (*Context Window*) | Capacidad máxima de tokens que un modelo puede procesar en una sola llamada de inferencia. | The maximum token capacity limit that a model can process in a single inference call. |
| Continual learning | Aprendizaje continuo (*continual learning*) | Estudio de cómo un sistema puede seguir aprendiendo de tareas nuevas y de la interacción sin olvidar lo aprendido; para un Agente, pasar poco a poco de inteligente a experto. | The study of how a system can keep learning from new tasks and interaction without forgetting what it learned; for an Agent, gradually going from smart to expert. |
| CrewAI | CrewAI | Marco de trabajo multi-agente basado en roles diseñado para orquestar equipos colaborativos de agentes. | A role-playing multi-agent framework designed to orchestrate collaborative agent teams. |
| Cross-encoder | Codificador cruzado (*cross-encoder*) | Modelo que procesa la consulta y el documento juntos y devuelve una puntuación de pertinencia más precisa pero más lenta; se usa en la reordenación. | A model that processes the query and document together and returns a more accurate but slower relevance score; used for reranking. |
| Defense in depth | Defensa en profundidad (*Defense in depth*) | Enfoque de seguridad por capas que combina múltiples salvaguardas especializadas en lugar de confiar en una sola. | A layered security approach combining multiple specialized safeguards rather than relying on a single one. |
| Dense retrieval | Recuperación densa (*Dense retrieval*) | Método de búsqueda semántica de documentos que utiliza incrustaciones vectoriales (*embeddings*) de alta dimensión. | A semantic document retrieval method using high-dimensional vector embeddings of text. |
| Distillation | Destilación (*Distillation*) | Proceso de transferir conocimiento y capacidades de un modelo grande (profesor) a un modelo más pequeño y rápido (estudiante). | The process of transferring knowledge and capabilities from a large model (teacher) to a smaller, faster model (student). |
| DPO (Direct Preference Optimization) | Optimización Directa de Preferencias (DPO) | Método de alineación que optimiza directamente los pesos del modelo a partir de datos de preferencia humana sin un modelo de recompensa separado. | An alignment method that directly optimizes model weights from human preference data without a separate reward model. |
| Edge Agent | Agente en el dispositivo (*Edge Agent*) | Agente que se ejecuta localmente en el dispositivo del usuario (teléfono, portátil) en lugar de en servidores en la nube centralizados. | An Agent that runs locally on a user's device (phone, laptop) rather than on centralized cloud servers. |
| Embedding | *Embedding* / incrustación | Vectores numéricos de alta dimensión que representan el significado semántico de fragmentos de texto u objetos. | High-dimensional numerical vectors representing the semantic meaning of text chunks or objects. |
| Evaluation | Evaluación (*Evaluation*) | Proceso sistemático que fija tareas, entornos y verificadores para medir la tasa de éxito, la calidad, el coste y la seguridad de un Agente, y analizar las causas de los fallos. | A systematic process that fixes tasks, environments, and verifiers to measure an Agent's success rate, quality, cost, and safety, and to analyze the causes of failures. |
| External Learning | Aprendizaje externalizado (*External Learning*) | Conservación y recuperación de conocimiento fuera de los parámetros del modelo (en bases vectoriales, archivos, memorias) en lugar de ajustar parámetros. | Retaining and retrieving knowledge outside model weights (in vector databases, files, memories) rather than fine-tuning parameters. |
| Few-shot Adaptation | Ejemplos *few-shot* (*few-shot examples*) | Técnica que incluye en el prompt algunos ejemplos completos para mostrar al modelo el comportamiento esperado en lugar de describirlo de forma abstracta. | A technique that includes a few complete examples in the prompt to show the model the expected behavior instead of describing it abstractly. |
| Fine-Tuning | Ajuste fino (*Fine-Tuning*) | Proceso de entrenar un modelo base en conjuntos de datos especializados para adaptar sus parámetros a tareas específicas. | The process of training a base model on specialized datasets to adapt its parameters for specific tasks or domains. |
| Freeform Tool Calling | Llamada a herramientas en formato libre (*Freeform Tool Calling*) | Modo de llamada a herramientas a nivel de API donde el modelo envía texto sin formato a una herramienta en lugar de JSON estricto. | An API-level tool-calling mode where the model sends raw text to a tool instead of strict JSON. |
| Full-duplex | Dúplex completo (*full-duplex*) | Modo de conversación por voz en el que el modelo escucha y habla al mismo tiempo, de modo que puede ser interrumpido y reaccionar sin esperar a que termine el turno. | A voice conversation mode in which the model listens and speaks at the same time, so it can be interrupted and react without waiting for the turn to end. |
| Function calling | Llamada a funciones (*Function Calling*) | Mecanismo donde el modelo genera parámetros estructurados (generalmente JSON) para ejecutar funciones o herramientas externas. | A mechanism where the model outputs structured parameters (usually JSON) to execute external program functions or tools. |
| Graph Engineering | Ingeniería de grafos (*Graph Engineering*) | Perspectiva de ingeniería centrada en el grafo de ejecución: cómo se componen varias unidades de ejecución (nodos, conexiones, traspasos y puntos de control) en un sistema multi-agente. | An engineering perspective centered on the execution graph: how multiple execution units (nodes, connections, handoffs, checkpoints) are composed into a multi-agent system. |
| GRPO (Group Relative Policy Optimization) | Optimización de Política Relativa de Grupo (GRPO) | Algoritmo de RL (usado en DeepSeek-R1) que genera un grupo de rollouts por tarea y calcula la ventaja relativa de cada uno respecto al grupo, sin modelo de valor independiente. | An RL algorithm (used in DeepSeek-R1) that generates a group of rollouts per task and computes each one's relative advantage within the group, without a separate value model. |
| Guardrails | Barreras de seguridad (*Guardrails*) | Mecanismos que aplican la restricción, la verificación y la corrección a las entradas, las llamadas a herramientas y las salidas, para evitar comportamientos inseguros o no autorizados. | Mechanisms that apply constraints, verification, and correction to inputs, tool calls, and outputs to prevent unsafe or unauthorized behavior. |
| Hallucination | Alucinación (*Hallucination*) | Fenómeno donde un LLM genera respuestas incorrectas o no fundamentadas con alta confianza. | A phenomenon where an LLM generates confident but factually incorrect or ungrounded responses. |
| Harness | Harness | Todo lo que rodea al modelo dentro de un Agente: gestión del contexto, interfaces de herramientas, restricción, verificación y corrección. Agente = modelo + Harness. | Everything around the model in an Agent: context management, tool interfaces, constraints, verification, and correction. Agent = Model + Harness. |
| Harness Engineering | Ingeniería de Harness (*Harness Engineering*) | Disciplina que organiza la construcción del contexto, la planificación de herramientas, los permisos, la verificación y la recuperación de errores en un sistema ejecutable que permite al modelo completar tareas de forma continuada. | The discipline of organizing context construction, tool scheduling, permissions, verification, and error recovery into a runnable system that lets the model complete tasks continuously. |
| HITL (Human-in-the-Loop) | Humano en el ciclo (*human-in-the-loop*, HITL) | Patrón en el que el sistema pide a una persona que juzgue o confirme los pasos de alto riesgo o ambiguos antes de continuar. | A pattern in which the system asks a person to judge or confirm high-risk or ambiguous steps before continuing. |
| In-Context Learning | Aprendizaje en contexto (*In-Context Learning*) | Capacidad de un modelo para aprender temporalmente nuevas reglas o comportamientos a partir del contexto sin cambiar sus pesos. | The ability of a model to temporarily learn new rules, patterns, or behaviors from prompts/context without changing its weights. |
| Inference | Inferencia (*Inference*) | Fase de ejecución donde un modelo entrenado procesa entradas y genera predicciones o texto de salida. | The execution phase where a trained model processes inputs and generates output predictions or text. |
| Jailbreak | *Jailbreak* | Intento de inducir al modelo, mediante prompts manipuladores, a infringir sus normas de seguridad. | An attempt to induce the model, through manipulative prompts, to break its safety rules. |
| KV Cache | Caché KV / *KV Cache* | Caché que guarda las claves (Key) y los valores (Value) ya calculados de los tokens anteriores para no repetir el cálculo; un prefijo estable favorece su reutilización. | A cache that stores the already computed Keys and Values of previous tokens to avoid recomputation; a stable prefix favors its reuse. |
| Lethal trifecta | Tríada letal (*lethal trifecta*) | Combinación de riesgo descrita por Simon Willison: acceso a datos privados, contacto con contenido no fiable y capacidad de comunicarse con el exterior; juntas permiten exfiltrar datos mediante inyección de prompts. | A risk combination described by Simon Willison: access to private data, exposure to untrusted content, and the ability to communicate externally; together they allow data exfiltration through prompt injection. |
| Linter | Linter / Analizador estático | Herramienta de análisis estático utilizada por Coding Agents para detectar problemas de sintaxis o estilo antes de la ejecución. | A static code analysis tool used by Coding Agents to detect syntax or style issues before execution. |
| LLM-as-a-Judge | *LLM-as-a-Judge* (evaluación por modelo) | Técnica de evaluación en la que un modelo evaluador independiente puntúa las respuestas siguiendo un criterio de puntuación (*Rubric*). | An evaluation technique in which an independent evaluator model scores responses against a rubric. |
| Loop Engineering | Ingeniería de bucles (*Loop Engineering*) | Diseño de bucles con los que el Agente recorre de forma continuada el ciclo «determinar el siguiente trabajo — ejecutar — verificar — registrar el progreso» y decide si continúa, espera, traspasa o termina. | Designing loops in which the Agent continuously cycles through "determine next work — execute — verify — record progress" and decides whether to continue, wait, hand off, or stop. |
| Manager pattern | Patrón de gestor / Manager (*Orchestration Pattern*) | Patrón multi-agente en el que un Manager Agent centralizado descompone, asigna y consolida las tareas, mientras los subagentes asumen cada uno su trabajo especializado. | A multi-agent pattern in which a centralized Manager Agent decomposes, assigns, and consolidates tasks while sub-agents each handle specialized work. |
| MCP (Model Context Protocol) | *Model Context Protocol* (MCP) | Protocolo abierto publicado por Anthropic en 2024 que ofrece una forma unificada de descubrir y llamar herramientas y fuentes de datos externas. | An open protocol released by Anthropic in 2024 that provides a unified way to discover and call external tools and data sources. |
| Memory | Memoria del usuario / memoria | Sistema que permite almacenar, recuperar y actualizar información del usuario o del entorno a lo largo de múltiples sesiones. | Mechanism for persisting, retrieving, and updating user state, preferences, and long-term knowledge across multiple sessions. |
| Mid-training | *Mid-training* / pre-entrenamiento continuado (CPT) | Etapa de entrenamiento entre el preentrenamiento y el posentrenamiento que continúa el aprendizaje sobre la distribución objetivo (idioma, dominio, código o contexto largo). | A training stage between pre-training and post-training that continues learning on the target distribution (language, domain, code, or long context). |
| Model as Agent | «El modelo como Agente» (*Model as Agent*) | Tendencia en la que el modelo asume, mediante el posentrenamiento, cada vez más decisiones que antes orquestaba el Harness, como la llamada a herramientas. | A trend in which the model takes on, through post-training, more and more decisions previously orchestrated by the Harness, such as tool calling. |
| Multi-agent collaboration | Colaboración multi-agente | Arquitectura donde múltiples Agentes especializados trabajan juntos compartiendo información para resolver tareas complejas. | A system architecture where multiple specialized Agents work together, sharing information to solve complex tasks. |
| Multi-agent debate | Debate multi-agente | Patrón donde varios Agentes discuten y critican las ideas de los demás para alcanzar una decisión sintetizada más precisa. | A pattern where multiple Agents discuss and critique each other's ideas to reach a synthesized, more accurate decision. |
| Observability | Observabilidad (*Observability*) | Capacidad de monitorear, rastrear y auditar los estados internos, acciones e historiales de decisiones de un sistema de Agentes. | The ability to monitor, trace, and audit the internal states, actions, and decision histories of an Agent system. |
| Observation | Observación (*Observation*) | Respuesta o datos que recibe un Agente del entorno o herramienta tras ejecutar una acción. | The data or environment response received by an Agent after executing an action or calling a tool. |
| Observation Space | Espacio de observación (*Observation Space*) | Conjunto de observaciones que el Agente puede recibir (resultados de herramientas, capturas, eventos, mensajes del usuario). | The set of observations an Agent can receive (tool results, screenshots, events, user messages). |
| On-policy / Off-policy | En política / fuera de política (*On-policy* / *Off-policy*) | Distinción según si los datos de entrenamiento los genera la política actual (*on-policy*) o una política distinta o anterior (*off-policy*). | The distinction of whether training data is generated by the current policy (on-policy) or by a different or older policy (off-policy). |
| On-Policy Distillation | Destilación en política (*On-Policy Distillation*) | Destilación en la que el estudiante genera sus propias trayectorias y el profesor supervisa cada token de los estados a los que realmente llega, lo que da una supervisión densa a partir de un rollout. | Distillation in which the student generates its own trajectories and the teacher supervises every token in the states it actually reaches, giving dense supervision from a single rollout. |
| Optimistic locking | Bloqueo optimista (*Optimistic locking*) | Mecanismo de control de concurrencia que permite operaciones concurrentes sin bloqueos, verificando la consistencia solo al guardar. | A concurrency control mechanism that allows concurrent operations without locks, verifying data consistency only at save time. |
| Orchestration | Orquestación / orquestador (*Orchestration*) | Forma de organizar la ruta de ejecución en la que un centro decide los pasos de modelos, herramientas o Agentes; el orquestador es el componente que lo hace. | A way of organizing the execution path in which a central component decides the steps of models, tools, or Agents; the orchestrator is that component. |
| Peer-to-peer collaboration | Colaboración entre pares (*Peer Collaboration Pattern*) | Patrón multi-agente en el que un número reducido de miembros colabora directamente sobre un mismo producto, trabajan en paralelo y se retroalimentan sin un gestor central. | A multi-agent pattern in which a small number of members collaborate directly on a shared product, working in parallel and giving each other feedback without a central manager. |
| Poka-yoke | A prueba de errores (*Poka-yoke*) | Filosofía de diseño (proveniente de la industria manufacturera japonesa) que hace imposible cometer ciertos errores desde el propio diseño; aplicada a las interfaces de herramientas. | A design philosophy (from Japanese manufacturing) that makes certain errors impossible by design; applied here to tool interfaces. |
| Policy | Política (*Policy*) | Estrategia de toma de decisiones en Aprendizaje por Refuerzo que asigna observaciones a acciones; en un Agente, el LLM desempeña este papel. | The decision-making strategy in Reinforcement Learning that maps observations to actions; in an Agent, the LLM plays this role. |
| Post-training | Posentrenamiento (*Post-training*) | Etapas (SFT, aprendizaje por refuerzo, DPO, destilación) que, sobre un modelo preentrenado, moldean comportamientos como el seguimiento de instrucciones, el razonamiento y la llamada a herramientas. | Stages (SFT, reinforcement learning, DPO, distillation) that, on top of a pre-trained model, shape behaviors such as instruction following, reasoning, and tool calling. |
| Pre-training | Preentrenamiento (*Pre-training*) | Etapa inicial de entrenamiento donde un modelo aprende patrones generales del lenguaje y conocimiento del mundo desde grandes corpus. | The initial stage of training where a language model learns general language patterns and world knowledge from large-scale text corpora. |
| Prompt | Prompt / Instrucción | Cualquier entrada escrita proporcionada a un modelo de lenguaje para desencadenar una respuesta o decisión. | Any written input provided to a language model to trigger a text response or tool-calling decision. |
| Prompt Cache | *Prompt Cache* / caché de prompts | Optimización a nivel de API que reutiliza entre peticiones la Caché KV de un prefijo estable, reduciendo la latencia y el coste. | An API-level optimization that reuses the KV Cache of a stable prefix across requests, reducing latency and cost. |
| Prompt Engineering | Ingeniería de prompts (*Prompt Engineering*) | Práctica de diseñar y refinar prompts de sistema y usuario para optimizar las salidas y el comportamiento del LLM. | The practice of designing and refining system and user prompts to optimize LLM outputs and behavior. |
| Prompt injection | Inyección de prompts (*Prompt injection*) | Ataque que intenta convertir datos de entrada en instrucciones de control; puede llegar en la entrada del usuario o, de forma indirecta, a través de páginas web, documentos o resultados de herramientas. | An attack that tries to turn input data into control instructions; it can arrive in user input or, indirectly, through web pages, documents, or tool results. |
| Prompt leak | Filtración de prompt (*Prompt leak*) | Vulnerabilidad donde un atacante fuerza a un Agente a emitir su prompt del sistema interno o instrucciones privadas. | An exploit where an attacker forces an Agent to output its internal system prompt or private instructions. |
| Proposer–Reviewer | Proponente-Revisor (*Proposer–Reviewer*) | Patrón que encarga la producción y la evaluación a dos roles independientes: el revisor juzga con un contexto propio y examina el resultado real (render, salida de pruebas, parámetros de llamada). | A pattern that assigns production and evaluation to two independent roles: the reviewer judges with its own context and examines the actual result (rendering, test output, call parameters). |
| Pydantic schema | Esquema de Pydantic (*Pydantic schema*) | Definición de estructura de datos en Python utilizada para validar parámetros devueltos durante llamadas a herramientas. | A Python library used to define data structures and validate parameters returned during tool calls. |
| RAG (Retrieval-Augmented Generation) | Generación aumentada por recuperación (RAG) | Arquitectura que recupera documentos relevantes de una base de conocimiento y los añade al contexto para fundamentar la respuesta del LLM. | An architecture that retrieves relevant documents from a knowledge base and adds them to the context to ground the LLM's response. |
| ReAct | ReAct (Reasoning + Acting) | Implementación típica del bucle del Agente que alterna razonamiento sobre la situación y acciones con herramientas externas. | A typical implementation of the Agent loop that alternates reasoning about the situation with actions using external tools. |
| Reasoning | Razonamiento / pensamiento | Proceso interno del modelo previo a actuar o responder; los modelos de razonamiento lo generan explícitamente como tokens de pensamiento, y este libro abrevia esa información como `reasoning`. | The model's internal process before acting or answering; thinking models generate it explicitly as thinking tokens, and this book abbreviates that information as `reasoning`. |
| Reciprocal Rank Fusion (RRF) | Fusión por rango recíproco (RRF) | Algoritmo de búsqueda híbrida que combina las clasificaciones de varias vías de recuperación (por ejemplo, dispersa y densa) a partir de la posición de cada documento en ellas. | A hybrid search algorithm that combines the rankings of several retrieval paths (e.g., sparse and dense) based on each document's position in them. |
| Reflection | Reflexión (*Reflection*) | Proceso por el que un Agente forma, a partir de experiencias concretas, conocimientos más generales que guarda para orientar decisiones posteriores. | The process by which an Agent forms more general insights from concrete experiences and stores them to guide later decisions. |
| Reinforcement Learning (RL) | Aprendizaje por refuerzo (RL) | Paradigma de ML donde un Agente aprende políticas óptimas mediante interacciones de ensayo y error y recompensas en un entorno. | A machine learning paradigm where an Agent learns optimal decision policies through trial-and-error interactions and rewards in an environment. |
| Reranking | Reordenación (*reranking*) / reordenador | Paso de RAG que vuelve a puntuar y ordenar los candidatos recuperados, normalmente con un codificador cruzado. | A RAG step that re-scores and re-orders the retrieved candidates, usually with a cross-encoder. |
| Reward hacking | Fraude de recompensa (*Reward Hacking*) | Situación en la que la política aprovecha defectos de las reglas de recompensa para obtener una puntuación alta sin completar realmente la tarea. | A situation in which the policy exploits flaws in the reward rules to obtain a high score without actually completing the task. |
| Reward model | Modelo de recompensa (*Reward Model*) | Modelo entrenado para puntuar respuestas o trayectorias; según evalúe el resultado o el proceso, se denomina ORM o PRM. | A model trained to score responses or trajectories; called ORM or PRM depending on whether it evaluates the outcome or the process. |
| RLVR (Reinforcement Learning with Verifiable Rewards) | Aprendizaje por refuerzo con recompensas verificables (RLVR) | Aprendizaje por refuerzo cuya recompensa la calcula un programa que comprueba directamente los requisitos de la tarea (pruebas, respuestas exactas, estado del entorno). | Reinforcement learning whose reward is computed by a program that directly checks the task requirements (tests, exact answers, environment state). |
| Rollout | *Rollout* | Ejecución completa de una tarea por la política desde el estado inicial hasta el final, que produce una trayectoria con observaciones, acciones y recompensas. | A complete run of a task by the policy from the initial state to the end, producing a trajectory with observations, actions, and rewards. |
| Rubric | Criterio de puntuación (*Rubric*) | Lista de juicios, partida por partida, que explica cómo se dictamina el resultado; la usan evaluadores humanos y modelos evaluadores. | An item-by-item list of judgments explaining how the result is graded; used by human evaluators and evaluator models. |
| Sandbox | Sandbox / Entorno aislado | Entorno de ejecución aislado y seguro donde se pueden ejecutar de forma segura comandos o código generado no confiable. | An isolated, secure execution environment where untrusted code or commands generated by an Agent can be run safely. |
| Sandbox escape | Fuga del Sandbox (*Sandbox escape*) | Vulnerabilidad grave de seguridad donde el código malicioso ejecutado por un Agente rompe los límites de su entorno aislado. | A severe security vulnerability where malicious code executed by an Agent breaks out of its sandbox boundaries. |
| Scratchpad | Espacio de trabajo propio del Agente (*Scratchpad*) | Zona del sistema de archivos reservada a cada instancia de Agente para guardar sus notas, archivos intermedios y resultados provisionales. | An area of the file system reserved for each Agent instance to store its notes, intermediate files, and provisional results. |
| SFT (Supervised Fine-Tuning) | Ajuste fino supervisado (SFT) | Ajuste fino que enseña al modelo a responder y actuar a partir de demostraciones de entradas y salidas esperadas. | Fine-tuning that teaches the model to respond and act from demonstrations of inputs and expected outputs. |
| Sidecar | Sidecar | Módulo de comprobación independiente que se ejecuta junto al bucle principal del Agente para auditar llamadas a herramientas o resultados antes de que tengan efectos externos. | An independent checking module running alongside the Agent's main loop to audit tool calls or results before they have external effects. |
| Sidecar bypass queries | Consultas laterales Sidecar (*Sidecar bypass queries*) | Consultas independientes enviadas en paralelo con el flujo principal, por ejemplo a una base de conocimiento o a un verificador, sin alterar el contexto principal. | Independent queries sent in parallel with the main flow, e.g. to a knowledge base or a verifier, without altering the main context. |
| Sparse retrieval | Recuperación dispersa (*Sparse retrieval*) | Métodos de búsqueda tradicionales basados en palabras clave (como BM25) que buscan coincidencias exactas de tokens en documentos. | Traditional keyword-based search methods (like BM25) that look for exact token matches in documents. |
| SSRF (Server-Side Request Forgery) | Falsificación de Petición en el Lado del Servidor (SSRF) | Vulnerabilidad donde un Agente es manipulado para enviar peticiones no autorizadas a servicios de la red interna. | A vulnerability where an Agent is manipulated into sending unauthorized requests to internal network services. |
| Static prefix | Prefijo estable (*Static prefix*) | Parte del contexto que no cambia entre peticiones (prompt del sistema, definiciones de herramientas) y que se coloca al principio para reutilizar la Caché KV. | The part of the context that does not change between requests (system prompt, tool definitions), placed at the start so the KV Cache can be reused. |
| Sub-agents | Subagentes / subagentes (*Sub-agents*) | Agentes en los que un Agente principal delega subtareas con su propio contexto, herramientas y modelo, y de los que recoge los resultados. | Agents to which a primary Agent delegates sub-tasks with their own context, tools, and model, and from which it collects the results. |
| System Prompt | Prompt del sistema (*System Prompt*) | Instrucciones que construye el desarrollador o el Harness para definir la identidad, las reglas y la forma de trabajar del Agente; suele formar parte del prefijo estable. | Instructions built by the developer or the Harness that define the Agent's identity, rules, and way of working; usually part of the stable prefix. |
| System Prompt Learning | Aprendizaje del prompt de sistema (*System Prompt Learning*) | Forma de actualizar la experiencia, propuesta por Andrej Karpathy, en la que el modelo escribe lo aprendido como instrucciones explícitas en su prompt en lugar de en sus parámetros. | A way of updating experience, proposed by Andrej Karpathy, in which the model writes what it learned as explicit instructions in its prompt rather than in its weights. |
| Task decomposition | Descomposición de tareas (*Task decomposition*) | Proceso de dividir un objetivo complejo de múltiples pasos en subtareas más pequeñas, manejables y secuenciales. | The process of dividing a complex, multi-step goal into smaller, manageable, and sequential sub-tasks. |
| Time-to-First-Token (TTFT) | Latencia del primer token (TTFT) | Tiempo desde el envío de la petición hasta la llegada del primer token de salida del modelo. | The time from sending the request to receiving the model's first output token. |
| Token | Token | Unidad semántica básica (caracteres o fragmentos de palabras) procesada por modelos de lenguaje grandes. | The basic semantic unit (characters or word pieces) processed by large language models. |
| Tool calling | Llamada a herramientas (*Tool calling*) | Mecanismo mediante el cual un LLM decide invocar un programa o API externa con argumentos específicos. | The mechanism where an LLM chooses to invoke an external program or API with specific arguments. |
| Trajectory | Trayectoria (*trajectory*) | Secuencia de observaciones, acciones y resultados acumulada durante la ejecución de una tarea; el historial de mensajes es una forma de registrarla. | The sequence of observations, actions, and results accumulated while executing a task; the message history is one way to record it. |
| Vector database | Base de datos vectorial (*Vector database*) | Base de datos especializada optimizada para almacenar, indexar y consultar incrustaciones vectoriales semánticas de alta dimensión. | A specialized database optimized for storing, indexing, and querying high-dimensional semantic vector embeddings. |
| Verifier | Verificador (*Verifier*) | Componente que conecta el objetivo de la tarea con evidencias comprobables (pruebas, estado del entorno, reglas o un modelo evaluador) y dictamina si el resultado es correcto; suele ser el cuello de botella de los bucles autónomos. | A component that links the task goal to checkable evidence (tests, environment state, rules, or an evaluator model) and decides whether the result is correct; often the bottleneck of autonomous loops. |
| Vibe coding | Vibe coding | Estilo de desarrollo informal donde un humano dirige Agentes con ideas e intenciones de alto nivel en lugar de escribir código línea por línea. | An informal term describing development where a human directs agents with high-level ideas and intents instead of writing code line-by-line. |
| VLA (Vision-Language-Action) | Modelo de visión, lenguaje y acción (VLA) | Modelo que, a partir de la imagen actual, la instrucción en lenguaje natural y el estado del robot, genera directamente las acciones de control. | A model that, from the current image, a natural-language instruction, and the robot state, directly outputs control actions. |
| Whisper coding | Whisper coding | Forma de colaborar de viva voz con un Agente: se le dicta un esquema o una instrucción y el Agente busca material, redacta o escribe código, que después se revisa. | A way of collaborating with an Agent by voice: you dictate an outline or instruction and the Agent gathers material, drafts text, or writes code, which you then review. |
| Workflow | Flujo de trabajo (*Workflow*) | Orquestación predefinida que organiza modelos y herramientas mediante rutas de código fijadas por el desarrollador. | Predefined orchestration that organizes models and tools along code paths fixed by the developer. |
| World model | Modelo del mundo (*world model*) | Modelo que, a partir del estado actual y de una acción candidata, predice el estado siguiente, lo que permite planificar y ejecutar de forma especulativa. | A model that predicts the next state from the current state and a candidate action, enabling planning and speculative execution. |
| Zero-shot Adaptation | Adaptación cero ejemplos (*Zero-shot Adaptation*) | Realización de una tarea basada puramente en instrucciones del prompt sin proporcionar ejemplos de la entrada/salida esperada. | Performing a task based purely on prompt instructions without providing any examples of the expected input/output. |
